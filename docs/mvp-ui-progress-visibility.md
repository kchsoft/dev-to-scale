# MVP UI Progress Visibility

이 브랜치는 `feature/playable-mvp`에서 파생되어 게임 진행 상태를 더 직관적으로 보여주는 UI를 실험한다.

- Day 진행 바: 현재 하루가 0→100%로 차오르고 완료 시 Day +1
- Pause 상태에서는 진행 바도 그대로 멈춤
- x1/x2 속도에 맞춰 진행 바 속도도 변경
- 학습 중인 Skill 이름, 목표 Lv, N/M일, 진행률 표시
- 기능 개발은 Work 기반이므로 `N / ~M일`, `약 K일 남음` 형태로 현재 속도 기준 예상치를 표시
- Blocking 팝업이 뜨면 잠시 자동 Pause
- 팝업을 닫거나 대응 액션을 실행하면 팝업 전 속도(x1/x2)로 자동 재개
- 게임 종료 상태에서는 팝업을 닫아도 다시 재생하지 않음
